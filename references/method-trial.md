# 轻量级方法试验

主推荐按需配一张短试验卡：目标｜输入｜最少步骤｜比较基线｜成功、失败或无法判断标准｜结果收集｜局限。阈值来自用户目标或业务标准；自行建议的阈值标明待确认，不包装为专业标准。

| 任务 | 最小试验 | 边界 |
|---|---|---|
| 预测 | 历史留出或按时间顺序回测，与简单基线比较 | 禁止未来信息泄漏；数据不足不造分数 |
| 设计 | 局部原型或受控 A/B，记录目标与代价 | 小样本结果不普遍化 |
| 表达 | 改写一段/一页，让目标受众复述要点 | AI 自评仅辅助，无受众反馈仍未验证 |
| 优化 | 可比条件下比较指标及成本 | 同时变化的因素不直接归因为方法效果 |
| 决策 | 硬约束、敏感性与场景检查 | 排名稳定不代表实际收益达成 |

有输入、权限且属于用户任务的低风险操作直接实施并提供产物。缺条件则给最小补充项，明确“未执行”，保持 UNVERIFIED；不强迫用户做复杂试验。报告实际观测、数据来源和局限；AI 生成了方案不构成成功。真实结果只更新会话判断，个人经验持久化仍须预览与用户确认。
