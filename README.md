# Meta Method Discovery

**让 Agent 找到你还不知道的专业解法。**

一个帮助 AI Agent 发现专业方法的 Skill。你用日常语言描述问题，它从相关领域寻找成熟的算法、理论、原则或框架，结合你的条件给出解题路径，并把实际使用后的经验积累成个人方法库。

你会得到：**方法名称与原理、选择理由、所需输入、执行步骤，以及检验效果的办法。**

## 从问题到方法

### 动画动作很僵硬，不知道怎么调整

> “关键帧都摆好了，动作还是像机器人，应该从哪里改？”

**找到方法：动画十二原则中的 Timing & Spacing、缓入缓出、跟随与重叠动作。**

先选一段转身或抬手动作，调整关键姿态之间的间距，让起步、加速和停顿有变化；再给头发、衣服或手臂加入延迟与跟随。把“增加更多帧”的模糊尝试，变成对节奏、重量感和动作衔接的具体调整。

### 工艺参数太多，全组合实验做不起

> “温度、压力、速度都可能影响良率，逐个试很慢，全部组合又太贵。”

**找到方法：试验设计（DOE）中的部分析因设计、筛选设计与响应曲面法。**

先整理因子范围、测量误差和可能的交互作用，选择适合的筛选设计，找出值得继续研究的因子；再围绕这些因子做局部优化和确认试验。让每轮实验回答一个明确问题，逐步缩小搜索范围。

### 调参跑了很多轮，还是不知道下一次该试什么

> “每次训练都很贵，现在只能凭感觉改几个参数。”

**找到方法：贝叶斯优化；支持中间评估的训练任务还可以结合逐次减半。**

整理参数范围、目标指标和历史试验，利用已有结果选择下一组值得尝试的配置。训练中途的指标能反映最终表现时，再考虑提前停止较差配置，把预算留给更有希望的候选。

### 指标在慢慢变差，普通告警一直没响

> “每周只差一点，但一个月下来已经明显退步，怎么早点发现？”

**找到方法：统计过程控制中的 EWMA 与 CUSUM。**

用稳定时期的数据建立基线，先处理季节性或工况差异，再监控指标相对基线的持续偏移。将“单次有没有越线”扩展为“是否出现了连续的小变化”，并设计告警后的排查步骤。

### 用户评论很多，没有评分，怎么知道问题在变好还是变坏

> “几万条文字评论，想看大家最近最不满意什么，也不能调用外部LLM API。”

**找到方法：基于词典与规则的情感分析、方面级分析与时间聚合。**

按配送、质量、客服等业务维度整理评论，在本地处理否定词和情感表达，用人工抽样校准，再比较各维度负面提及比例随时间的变化。从“读完所有评论”转为追踪具体问题及其变化。

### 排班总有人不满意，手动调整又容易漏条件

> “既要覆盖岗位，又要避开不可用时间，还希望夜班分得公平。”

**找到方法：约束规划或混合整数规划。**

把可用时间、资质和岗位覆盖写成硬约束，将夜班负担差异写成优化目标，生成班表后逐条检查。条件变化时重新求解，把“凭经验调表”变成可检查的分配问题。

## 它怎么工作

```text
描述目标与困难 → 抽象问题 → 检索个人经验与专业方法
                                  ↓
                     核对来源、前提与任务约束
                                  ↓
                         给出步骤，开展小试验
```

- **发现你还不知道的方法**：从任务本身出发，优先寻找领域内的成熟解法，必要时借鉴邻近领域。
- **解释为什么适合**：把方法原理与你的数据、工具、时间和预算对应起来。
- **推进实际任务**：给出起手步骤、需要的输入和验证方式，继续完成当前能执行的部分。

## 构建自己的方法库

用过以后，经你确认，将问题、实际步骤、个性化调整、反馈与适用条件保存为 Markdown 经验。下次遇到类似问题，先找回相关记录，再判断是否复用。成功、部分成功和失败教训都可以保留，也支持更新、删除和导出。

每条经验都是带 YAML Frontmatter 的独立 Markdown 文件，放在用户可写的持久目录中。无需数据库或额外服务。配置与接口见 [个人方法记忆](references/personal-memory.md)。

## 快速开始

### 安装

将仓库克隆到宿主的技能目录，目录名保持 `meta-method-discovery`：

```sh
git clone https://github.com/Old-Sea-xz/meta-method-discovery.git
```

入口为 [SKILL.md](SKILL.md)。按宿主要求重新加载技能或开启新会话。

### 使用

```text
$meta-method-discovery

我的工艺有多个可调参数，全组合实验成本太高。
请帮我找到合适的试验方法，并给出第一轮怎么开始。
```

也可以直接描述问题，让支持自动发现的宿主调用这个 Skill。把已有数据、可用工具、时间和预算一起告诉 Agent，推荐会更有针对性。

方法发现使用宿主已有的搜索、阅读与执行工具。启用个人记忆另需 Python 3.10+、持久文件读写权限及 PyYAML：

```sh
python -m pip install -r scripts/requirements.txt
```
